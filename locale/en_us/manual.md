# SILENT MULTIVERSE NEXUS
- Manage every .md file in a project easily, quickly and safely.
- Export your whole project as an HTML file with a table of contents, clickable links, in the order you set.
- Use AI however you like, wherever you like, under your orders, answering the way you want.
- Talk to Ao to answer questions, ask for idea variations and brainstorm.
- Create a Discord bot so your players and friends can ask anything about the project.
- Write server-rule files so the bot can answer questions about them too.

# 1. QUICK START & PROJECT STRUCTURE
- Current Project: the active project is shown at the top of the sidebar. Create or switch projects at any time with the 📁 folder icon.
- Project Folder: holds your folders and Markdown (.md) files. Have as many projects as you want!
- Templates/: creation templates (e.g. cidade.md, npc.md, reinado.md). Edit them or add new ones directly in this folder.
- Style/: writing and mood guidelines (e.g. Tom_e_Clima.md). The base file follows the option chosen in Options; any other documents you put there are also used by the AI.
- memories/: recent history of local and Discord conversations. Only deleted by the Delete Memories button on the Actions page.
- exports/: HTML sourcebooks and reports.

# 2. LANGUAGE
- In Options → Language, choose Português (Brasil) or English (US).
- The AI answers in the new language right away (Expander, WorldBuilder, Council, Roleplay, chat and the Discord bot).
- The interface switches after restarting the program.
- Your lore files are not translated; new content generated by the AI follows the chosen language.

# 3. EDITOR SYNTAX & WRITING RULES
## Wikilinks [[File Name]]
- Whenever you reference another entity of your world, use double brackets (e.g. [[Kingdom of Lucius]]). Click the link in the editor to jump to it. If the document doesn't exist, the program offers to create it.
## Expansion Tags (<-- TODO: Reason)
- Right-click in the editor to insert the <-- TODO: tag, or type it yourself. After the colon, write what should be done.
- The Expander finds the tag and uses the AI to fill in that part following your instructions.
## GM Secrets vs Players
- Used by the Discord bot when answering players.
- To hide a whole file from players, put status: secret (or status: segredo) or tags: [secret] in its header.
- To hide a section, add [secret] (or [segredo]) to its heading (e.g. ### The Hidden Cult [secret]).
- Files or folders whose NAME contains a secret word (set in Options) are hidden too.
- Drafts: status: draft (or status: rascunho) keeps the file out of the AI context.

# 4. TALK TO AO & DISCORD BOT
## Local Chat
- Ao, inside the program, simulates the Discord bot: brainstorming, questions and discussions about the project.
- Right-click a file in the Editor and choose 'Ask Ao about this file' to attach the whole document to the conversation.
## Discord Bot
- Trigger (Prefix): how players call the bot on the server. E.g. !ao, $ao, &Supreme.
- GM Roles: whoever has these roles gets answers with the whole project, secrets included.
- Allowed/Blocked Channels: where the bot may or may not answer.
- Cooldown: wait time per user, to prevent spam.
- Dice: !r 1d20+5, !rolar 2d6+3 or !r 2d20kh1+3.

# 5. WORLDBUILDER PAGE
- Write the goal and click Run: the WorldBuilder plans and executes actions (create folders, create and improve files).
- Planned actions appear in the list as soon as planning finishes; the log shows each step in real time.
- Permissions (create folders, create files, improve files) are on the page itself.

# 6. ACTIONS PAGE
- Expander: looks for <-- TODO: tags in every file and generates the content with the AI. The previous version goes to logs/history.
- Auto Expander (Options): runs the Expander when you save with Ctrl+S or leave an edited file that contains the tag.
- Rebuild Context: refreshes what the AI knows about the project. The context is rebuilt automatically every 12h.
- Lore Audit: looks for historical inconsistencies, chronology holes and geographic contradictions.
- Sourcebook: compiles every file into an HTML with table of contents and links and opens it in your browser (it can be saved as PDF).
- Analyze Project Size: shows, per folder and file, how many tokens the project takes in the AI context (GM and players) and how much of the provider's limit that is.
- Backup: creates a .zip with the project and the data folder, at the root of the program's drive (or in the program folder if that isn't allowed).
- Delete Memories: erases local and Discord conversations.

# 7. SHORTCUTS
- [Ctrl + S]: save the file (and trigger the Auto Expander, if enabled).
- [F2]: rename the selected item in the Editor.
- [Ctrl + Mouse Wheel]: zoom.
- [Alt + Left / Right Arrow]: go back / forward between documents.
- [Ctrl + Z]: undo.
